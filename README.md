# Keys From Above Link Page

A premium piano-themed Linktree-style page built with Next.js, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open:

```txt
http://localhost:3000
```

## Deploy to Vercel

1. Create a new GitHub repository.
2. Upload these files.
3. Go to Vercel and import the repository.
4. Click Deploy.

## Edit links

Open `app/page.tsx` and edit the `links` array.
